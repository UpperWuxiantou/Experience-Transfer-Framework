# 经验推广框架（Experience Propagation Framework）

一个让 Agent 从经验中学习的轻量级推理框架。用户提供经验事件，Agent 提取结构化知识，通过属性共现传播机制预测新场景。推理依据来自用户经验而非 LLM 语料记忆，每条推断可追溯、可量化。

---

## 为什么做这个框架

直接问 LLM "遇到狼会怎样"——LLM 靠训练语料中的统计记忆回答。如果狼是虚构生物，LLM 无法正确判断。

本框架换了一种方式：Agent 从用户提供的真实经验中学习，将经验转化为结构化的属性知识，再通过属性之间的共现关系做推理传播。推理依据来自用户经验而非 LLM 的语料记忆，即使狼是虚构生物，只要属性匹配，Agent 也能从已有经验中推断出结论。

---

## 框架原理

### 学习阶段

用户用自然语言描述一条事件，Agent 提取四元组：主体、动作、客体、结果。然后为每个元素生成属性（如"老虎 → 食肉、有尖牙、攻击力高"），存入知识库。每次学习后自动合并同义属性名（"尖牙锋利度"和"尖牙致伤能力"归为同一属性），确保命名一致。

### 预测阶段

用户描述一个新场景，Agent 提取三元组（主体、动作、客体），生成属性，同时联网搜索补充实体属性。然后将这些属性在知识库的共现图上做传播匹配——如果知识库中学过"老虎（有尖牙）→ 攻击力高"，当新场景出现"狼（有尖牙）"时，Agent 自动推断出"狼也有攻击力高"。

每条传播结果附带量化距离：距离 0.00 完全可靠、0.33 可参考、大于 0.30 不采纳。最后 LLM 基于这些结构化证据给出推理结论。

---

## 核心特性

- 属性共现传播：在属性共现图上做推理，每条推断可追溯来源、可量化可靠度
- 属性归一化：LLM 自动合并同义属性名，防止命名不一致导致传播失效
- 联网属性增强：预测时自动搜索补充实体属性（DuckDuckGo，免费），网络不可用时静默降级
- 自动持久化：学习后自动保存知识库，重启程序自动恢复
- 兼容多种 LLM：支持 DeepSeek、通义千问、GLM、OpenAI、本地 Ollama 等，改三行配置即可切换

## 快速开始

```bash
# 安装
pip install openai python-dotenv duckduckgo_search

# 配置
# 编辑项目目录下的 .env 文件，填入你的 API Key
LLM_API_KEY=sk-your-key-here
LLM_MODEL=deepseek-chat
LLM_BASE_URL=https://api.deepseek.com/v1

# 运行（智能对话）
python "基于经验推广框架的用户交互agent.py"
```

## 项目结构

| 文件 | 说明 |
|------|------|
| 经验推广框架.py | 框架核心：知识库、属性归一化、提取器、联网搜索、ExperienceAgent |
| my_llm.py | LLM 交互封装（兼容 OpenAI 接口） |
| 基于经验推广框架的用户交互agent.py | 智能对话 Agent，自动识别学习/预测/聊天 |
| 基于经验推广框架的快速训练预测agent.py | 快速训练预测 Agent，文件学习后循环预测 |
| .env | 配置文件，填入 API Key 和模型参数 |

---

## 适用场景

- 需要 Agent 从少量经验中学习并推广到相似场景
- 需要推理过程可追溯、可解释，每步推断都有依据
- 希望 Agent 的推理依据来自用户经验而非 LLM 语料
- 构建特定领域的经验知识库，让 Agent 越用越懂
