# 经验推广框架（Experience Propagation Framework）

一个让 Agent 从经验中学习、用属性传播做推理的轻量级框架。用户提供经验事件，Agent 提取属性构建知识库，面对新场景时通过属性共现传播机制做推理。推理依据来自用户经验而非 LLM 语料记忆，每条推断可追溯来源、可量化可靠度。

---

## 为什么做这个框架

直接问 LLM "遇到狼会怎样"——LLM 靠训练语料中的统计记忆回答，推理过程不可控、不可追溯。如果狼是虚构生物，LLM 无法正确判断。

本框架让 Agent 换一种方式工作：不靠 LLM 语料记忆，而是从用户提供的真实经验中学习，自己构建知识库，自己做推理。

核心思路分三步：

第一步：属性提取。用户说"老虎扑过来咬伤了我"，Agent 不是整句记住，而是提取结构化知识——主体"老虎"有属性"食肉、有尖牙、攻击力高"。这就把一段自然语言转化成了机器可操作的属性数据。

第二步：属性匹配。用户问"遇到狼群怎么办"，Agent 提取狼的属性"食肉、有尖牙、群居"。这时 Agent 发现：老虎有"食肉、有尖牙"，狼也有"食肉、有尖牙"——属性匹配上了。

第三步：推理传播。Agent 的知识库里之前已经统计出：有"食肉"和"有尖牙"的实体，大概率也具备"危险"和"攻击力高"。于是 Agent 自动将"危险"传播到狼身上，完成推理。

整个过程 Agent 的推理依据来自用户提供的真实经验，不是 LLM 的语料记忆。即使狼是虚构生物，只要它的属性与已有经验匹配，Agent 依然能做出合理推断。

## 框架结构

```
用户输入（经验事件 / 预测场景）
         │
         ▼
 ┌─────────────────────────────────────┐
 │          Extractor（提取层）          │
 │  文本 → S-A-O-R / S-A-O → 属性      │
 └──────────┬──────────────────────────┘
            │
            ▼
 ┌──────────────────┐    ┌─────────────────────┐
 │  KnowledgeBase   │    │   WebSearcher       │
 │  实体属性表       │    │   DuckDuckGo搜索    │
 │  属性共现图       │◄───│   补充实体属性       │
 └──────┬───────────┘    └─────────────────────┘
        │
        ▼
 ┌─────────────────────────────────────┐
 │       属性传播（propagate）          │
 │  查询属性 → 共现图上传播 →           │
 │  量化距离（0.00~0.30）              │
 └──────────┬──────────────────────────┘
            │
            ▼
 ┌─────────────────────────────────────┐
 │   LLM 基于结构化证据做推理输出        │
 │   "狼：食肉(1.0) → 危险(1.0)        │
 │        有尖牙(1.0) → 攻击力高(0.67)" │
 └─────────────────────────────────────┘
            │
            ▼
         预测结果
```

## 核心流程

### 学习阶段

用户提供一条经验事件，Agent 提取四元组（主体、动作、客体、结果），为每个元素生成属性，注册到知识库。然后更新属性共现图（统计哪些属性经常同时出现），再归一化同义属性名（"尖牙锋利度"="尖牙致伤能力"）。每次学习后自动保存知识库。

### 预测阶段

用户描述一个新场景，Agent 提取三元组（主体、动作、客体），生成属性，同时联网搜索补充实体属性。然后将这些属性在共现图上做传播——找到与当前场景属性匹配的历史经验，通过共现关系推断出额外属性。每条传播结果附带量化距离（0.00完全可靠、0.33可参考、大于0.30不采纳）。最后 LLM 基于这些结构化证据给出自然语言结论。

---

## 核心特性

- 属性共现传播：在属性共现图上做推理，每条推断可追溯来源、可量化可靠度
- 属性归一化：LLM 自动合并同义属性名，防止命名不一致导致传播失效
- 联网属性增强：预测时自动搜索补充实体属性（DuckDuckGo，免费），网络不可用时静默降级
- 自动持久化：学习后自动保存知识库，重启程序自动恢复
- 兼容多种 LLM：支持 DeepSeek、通义千问、GLM、OpenAI、本地 Ollama 等，改三行配置即可切换

## 快速开始

```bash
# 安装
pip install openai python-dotenv duckduckgo_search

# 配置
# 编辑项目目录下的 .env 文件，填入你的 API Key
LLM_API_KEY=sk-your-key-here
LLM_MODEL=deepseek-chat
LLM_BASE_URL=https://api.deepseek.com/v1

# 运行（智能对话）
python "基于经验推广框架的用户交互agent.py"
```

## 适用场景

- 需要 Agent 从少量经验中学习并推广到相似场景
- 需要推理过程可追溯、可解释，每步推断都有依据
- 希望 Agent 的推理依据来自用户经验而非 LLM 语料
- 构建特定领域的经验知识库，让 Agent 越用越懂
